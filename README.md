# トークン憲章

[English](README.en.md) · 公開ページ：[日本語](https://nndahedeyo.github.io/token-charter/) / [English](https://nndahedeyo.github.io/token-charter/en/)

暗号資産プロジェクトが**約束を守っているか、守らせる仕組みがあるか**を、10の項目で採点して公開する台帳です。Wikipediaのように、誰でも出典つきで修正を提案でき、決まったルールを満たした変更だけが自動で反映されます。

## なぜ必要か

株式市場では、取引所・証券当局・社債管理者が、企業に約束を守らせています。暗号資産には、この「守らせる役」がいません。買い戻しの削減、発動しない還元の仕組み、日程のない採決、予定のない大量の保有分が、あちこちで起きています。

トークン憲章は、約束の中身と実行を同じ物差しで測り、誰でも確かめられる形で公開します。

## 何を測るか

| 区分 | 項目 |
| --- | --- |
| 発行体（6） | 1. 還元の約束　2. 約束の実行　3. 内部関係者の売却ルール　4. 定期的な報告　5. 罰則・担保　6. 説明責任 |
| 仕組み（4） | 7. 供給予定の確定　8. チェーン上の検証　9. 少数による介入　10. ルール変更の手続き |

各項目は0〜2点で、100点満点に換算します。発行体のない銘柄（BTCなど）は、仕組みの4項目だけで採点します。基準の詳細は [data/criteria.json](data/criteria.json) にあります。

**点数は投資の推奨ではありません。** 測っているのは「約束の信頼性」だけで、価格や将来性ではありません。

## 誰が点数を決めるか

運営者ではなく、[編集ルール（RULES.md）](RULES.md) が決めます。

1. 誰でも、出典つきで修正を提案できる
2. 機械が、形式と出典を自動で検査する
3. 承認できる人（実績で自動的に決まる）の承認がそろうと、自動で反映される（[RULES.md](RULES.md)）
4. 収益のデータは毎日自動で取り込むが、点数は自動では変わらない

## 参加する

## フォルダの中身

| 場所 | 中身 |
| --- | --- |
| `data/tokens.json` | 銘柄ごとの点数・要約・出典（ここを編集する） |
| `data/criteria.json` | 10項目の採点基準とランクの境目 |
| `scripts/` | 検査・ページ生成・収益データの取得 |
| `site/template.html` | 公開ページのひな形 |
| `.github/` | 自動検査・自動反映・毎日の公開の設定、提案のテンプレート |
